# Atribuição das Skills

Skills de terceiros vendorizadas em `.opencode/skills/` para uso **sob demanda** pelo agente.
Cada skill só entra no contexto quando é carregada — não há custo permanente além da descrição.

## GodotPrompter (MIT)

- **Fonte:** https://github.com/jame581/GodotPrompter (Jan Mesarč)
- **Licença:** MIT — cópia em `_LICENSE-GodotPrompter.txt`.
- **Skills importadas (curadas para o nosso roadmap):**
  `hud-system` (números de dano), `player-controller`, `physics-system`,
  `2d-essentials`, `resource-pattern`, `mobile-development`,
  `scene-organization` (prefabs), `component-system` (hitbox/hurtbox).
- Ao atualizar: suba a versão do repo e reimporte só estes diretórios.

## Godot MCP Toolkit (companion skills)

- **Fonte:** `game/addons/godot_mcp_toolkit/CompanionSkills/` (do próprio addon instalado).
- `godot-mcp-toolkit` e `mcp-extension-creator`.

## Nossas

- `progression-idle` — regras do projeto (vault, MoSCoW, estrutura).
