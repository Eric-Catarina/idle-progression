# 📚 Referência: Mecânicas de Constelação / Signos / Nós

> **ARQUIVO DE REFERÊNCIA BRUTO — NÃO carregar por padrão.**
> Consultar apenas ao trabalhar na **Mecânica Transversal #3 do Mundo 1** (candidata: *Constelação / Star Map*).
> Objetivo: inspiração de jogos que usam constelações/signos/teias de nós como mecânica de RPG.

| Jogo | Sistema | Tipo | O que roubar |
| :--- | :--- | :--- | :--- |
| **Grim Dawn** | Devotions | Mapa de estrelas literal | Gasta pontos numa constelação; exige **afinidade** (cores); **completar** a constelação dá um poder temático |
| **Elder Scrolls Online** | Champion Points | Constelações agrupadas | 3 grupos (Guerreiro/Ladrão/Mago) com constelações e **estrelas encaixáveis** |
| **Skyrim / Elder Scrolls** | Birthsigns / Standing Stones + perk trees | Signos + UI de constelação | Árvores de perk **desenhadas como constelações**; Signos de atributo |
| **Genshin Impact** | Constellations | Nós por entidade | 6 nós por personagem, nomeados por mitos |
| **Honkai: Star Rail** | Eidolons + Paths | Nós/arquétipos | Nós por personagem + "caminhos" que definem o papel |
| **Final Fantasy XIII** | Crystarium | Grade de cristal | Progressão por **cristal** em grade por papel |
| **Final Fantasy X** | Sphere Grid | Grade de nós | Percorre e destrava nós gastando esferas |
| **Path of Exile** | Passive Tree | Teia imensa | "Constelação" como **teia interligada** com keystones |
| **Warframe** | Focus Schools | Teias de nós | Escolas com árvore própria |
| **Idleon** | Star Talents / Star Signs | Talentos + signos | Nome/escopo mais próximo do nosso |

| **Diablo IV** | Paragon Board | Tabuleiro de nós | Nós + glifos + portões por região |

## Direções de design sugeridas

- **Estrutura (Grim Dawn):** mapa de constelações com **afinidade** e **constelações completas** concedendo poderes.
- **Ramos (ESO):** constelações agrupadas por sistema — ex.: ramo de **combate**, **fortuna/drop**, **produção (Osíris)**, **mobilidade (mapas)**.
- **Apresentação (Skyrim):** UI de estrelas interligadas; **signos** como escolhas de "classe astral" opcionais.
